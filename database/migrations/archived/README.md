## Fresh Database Setup

For setting up a fresh database with all schema:

**Option 1: Using Schema Snapshot (Fast)**
```bash
# Load schema snapshot
php artisan db:wipe
php artisan migrate:install
mysql -u root -p sipbarv2 < database/schema/mysql-schema.sql

# Mark all archived migrations as executed
# (Laravel will handle this automatically via schema snapshot)

# Run only active migrations
php artisan migrate
```

**Option 2: Run All Migrations (Complete History)**
```bash
# Temporarily restore archived migrations
mv database/migrations/archived/*.php database/migrations/

# Run all migrations
php artisan migrate

# Re-archive old migrations
# (run archival process again)
```

## Re-running Archival Process

To archive migrations again in the future:

```bash
# 1. Generate new schema snapshot
php artisan schema:dump

# 2. Move old migrations (before today) to archived/
# PowerShell:
Get-ChildItem "database\migrations\*.php" | Where-Object { 
    $_.Name -notlike "$(Get-Date -Format 'yyyy_MM_dd')*" 
} | Move-Item -Destination "database\migrations\archived\" -Force

# 3. Verify
php artisan migrate:status
```
