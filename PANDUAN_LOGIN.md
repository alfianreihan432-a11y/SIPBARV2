# Panduan Login SIPBAR

Dokumen ini menjelaskan cara login ke sistem SIPBAR (Sistem Peminjaman Barang) untuk Guru dan Siswa.

## Cara Login

### 1. Akses Halaman Login
- Buka browser dan kunjungi URL aplikasi SIPBAR
- Klik tombol "Masuk" atau navigasi ke halaman login

### 2. Isi Form Login

#### Untuk Guru:
- **Email**: Gunakan email guru yang terdaftar di sistem (format: `nama@sipbar.sch.id`)
- **Password**: Masukkan password akun guru
- Centang "Ingat saya" (opsional) untuk tetap login di browser ini
- Klik tombol "Masuk"

#### Untuk Siswa:
- **Email**: Gunakan email siswa yang terdaftar di sistem (format: `nama@sipbar.sch.id`)
- **Password**: Masukkan password akun siswa
- Centang "Ingat saya" (opsional) untuk tetap login di browser ini
- Klik tombol "Masuk"

### 3. Password Default

Jika login pertama kali atau password belum diubah:

#### Guru:
- Password default: `guru123`

#### Siswa:
- Password default: `siswa123`

> ⚠️ **Penting**: Segera ganti password default setelah login pertama untuk keamanan akun.

### 4. Ganti Password

Untuk mengganti password:
1. Login ke akun
2. Buka menu "Profil Saya" (untuk siswa) atau menu pengaturan (untuk guru)
3. Pilih opsi "Keamanan" atau "Ganti Password"
4. Masukkan password lama dan password baru
5. Simpan perubahan

## Setelah Login

### Dashboard Guru:
Setelah berhasil login, guru akan diarahkan ke dashboard guru yang berisi:
- **Menu Peminjaman**: Melihat dan menyetujui permintaan peminjaman barang
- **Menu Inventaris**: Mengelola barang yang tersedia
- **Menu Pengembalian**: Memproses pengembalian barang
- **Menu QR Scan**: Memindai QR Code untuk konfirmasi pengambilan/pengembalian barang
- **Statistik**: Ringkasan aktivitas peminjaman

### Dashboard Siswa:
Setelah berhasil login, siswa akan diarahkan ke dashboard siswa yang berisi:
- **Menu Katalog**: Melihat barang yang tersedia untuk dipinjam
- **Menu Peminjaman Saya**: Melihat status peminjaman aktif
- **Menu Riwayat**: Melihat riwayat peminjaman sebelumnya
- **Menu Profil**: Mengelola profil dan foto profil
- **Menu Pengumuman**: Melihat informasi penting terkait peminjaman

## Tips Keamanan

1. **Jangan berbagi password** dengan orang lain
2. **Logout** setelah selesai menggunakan sistem, terutama jika menggunakan komputer bersama
3. **Ganti password** secara berkala
4. **Gunakan password yang kuat** (kombinasi huruf, angka, dan simbol)
5. **Jangan gunakan password yang sama** untuk berbagai akun

## Troubleshooting

### Tidak bisa login:
- Pastikan email dan password dimasukkan dengan benar
- Cek koneksi internet
- Pastikan akun sudah aktif dan tidak diblokir
- Hubungi admin jika masih mengalami masalah

### Halaman tidak muncul:
- Refresh halaman browser
- Clear cache browser
- Coba gunakan browser lain

### Error saat login:
- Periksa pesan error yang muncul
- Pastikan email terdaftar di sistem
- Hubungi admin sistem jika error berlanjut

## Kontak Bantuan

Jika mengalami masalah yang tidak dapat diselesaikan:
- Hubungi admin SIPBAR di sekolah
- Email: admin@sipbar.sch.id
- Atau datang ke ruang inventaris untuk bantuan langsung
